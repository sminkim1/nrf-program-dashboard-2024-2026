# 한국연구재단 공모사업 관측소

한국연구재단의 2024~2026년 공개자료를 바탕으로 조직별 공모사업의 주제, 지원 대상, 사업비와 기간을 비교하는 정적 HTML 대시보드입니다.

- 조사 기준일: **2026년 11월 11일**
- 수록 범위: **7개 본부, 93개 사업군, 208개 연도별 사업 기록**
- 근거 자료: **125개**
- 현재 8개 본부에 대한 조사 범위와 미확인 상태를 대시보드에 표시했습니다.

공개 근거를 확보한 주요 사업을 정리한 자료이며 **전체 공고의 전수 목록은 아닙니다**. 2026년은 기준일까지 확인한 자료입니다. 미확인은 해당 조직이나 연도에 사업이 없다는 뜻이 아닙니다. 이 프로젝트는 한국연구재단의 공식 서비스가 아닙니다.

[사업 대시보드](https://sminkim1.github.io/nrf-program-dashboard-2024-2026/) · [독립 재검증 보고서](https://sminkim1.github.io/nrf-program-dashboard-2024-2026/audit.html)

## 2027 정부 R&D 예산안과 기존사업 매칭

[2027 예산·사업 대응 분석](https://sminkim1.github.io/nrf-program-dashboard-2024-2026/budget-2027.html)을 별도 제공합니다. 기준일은 2026년 11월 12일이며 국회 확정예산이 아닌 정부 예산안을 분석했습니다.

- 국가과학기술자문회의 편성안 본문에 금액이 명시된 92개 사업·세부트랙·기관별 배정항목을 모두 보존하고 부처 자료의 주요 항목을 보완했습니다. 정부 전체 세부사업의 전수 목록은 아닙니다.
- 기존 사업의 직접 대응, 공식 개편·승계, 기술·정책 연관, 신규 항목, 연속성 미확인을 구분했습니다.
- 한국연구재단 기존 기록 208건·공식 연간표 822행과 연결하고, 타 기관 사업과 NRF 공동 참여 항목을 구분했습니다.
- 같은 범위의 전년 예산이 확인될 때만 증감을 계산합니다. 분야 총액·부처 총액·세부사업 예산은 중복될 수 있어 합산하지 않습니다.
- 전체 매칭표는 `budget-2027-matching.csv`, 국가 원문 항목 대조표는 `budget-2027-inventory.csv`, 구조화 데이터는 `budget-2027.json`에서 내려받을 수 있습니다.

## 독립 재검증 결과

다른 에이전트들이 초기 123개 기록을 독립적으로 대조한 결과, **초기 자료에는 누락이 있었습니다**. 실제 공모 근거가 확인된 85개 기록을 보완하고, 기존 지원대상·지원기간 오류 2건을 정정했습니다.

- 공식 2024·2025·2026 연간 사업표의 822개 행을 초기 자료와 대조했습니다. 행 수는 공모형 사업의 총개수가 아닙니다.
- 세부 공모 유형 130개를 별도로 대조했습니다. 연간표 행과 중복될 수 있어 합산하지 않습니다.
- 신규사업공모 게시판의 기간 검색과 연도별 보완 검색 22개 페이지를 수집하고, 게시물 번호로 중복 제거한 공식 원장 1,000건을 제공합니다. 다른 사업연도·수정·영문 중복·인사 모집·행사 안내 등도 보존돼 있어 사업 총수와 다릅니다.
- 연간표에만 확인된 공고 계획과 실제 실행 공고를 구분했습니다. 남아 있는 부분 수록·미수록 후보·미확인 항목을 보고서에 공개합니다.

**현재도 모든 공모와 개별 RFP의 주제·대상·사업비까지 전수 검증·수록했다고 보장하지 않습니다.** 연간표에 생략된 국제협력 세세부, 다른 게시판의 공모, 선행 공고와 연도·재공모 정규화 등이 남아 있습니다.

## 주요 기능

- 조직·부서·연도·키워드별 사업 검색
- 사업 주제·대상·사업비·기간의 3개년 비교
- 과제당 지원액과 총사업예산, 간접비 등 금액 기준 구분
- 근거 원문과 보완 자료 링크
- CSV·JSON 및 오프라인 HTML 내려받기
- 모바일 화면 지원

출처와 조사·비교 기준은 대시보드의 **조직·출처·조사 범위** 탭과 각 사업의 상세 비교 화면에서 확인할 수 있습니다. 신청 자격과 지원 금액은 최종 공고 원문을 확인해 주세요.

## 파일

| 파일 | 용도 |
| --- | --- |
| `index.html` | 데이터와 CSS·JavaScript를 모두 포함한 대시보드 |
| `data.json` | 별도 활용을 위한 전체 조사 데이터 |
| `.nojekyll` | GitHub Pages에서 정적 파일을 그대로 게시하도록 설정 |
| `audit.html` | 초기 목록의 누락·정정·완전성 한계를 담은 독립 재검증 보고서 |
| `audit.json` | 연간표·유형 대조와 공식 게시물 원장 데이터 |
| `audit-inventory.csv` | 연간표·세부유형별 초기 수록 대조표 |
| `official-call-archive.csv` | 수집한 공식 신규공모 게시물 원장 |

외부 라이브러리나 빌드 과정이 필요하지 않습니다. `index.html`을 브라우저에서 직접 열어 사용할 수 있습니다. 원문 링크를 여는 경우에는 인터넷 연결이 필요합니다.

## GitHub Pages 게시

1. 이 폴더의 파일을 GitHub 공개 저장소 루트에 업로드합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
4. 게시할 브랜치(예: `main`)와 **`/(root)`**를 선택한 후 저장합니다.
5. Pages 배포가 완료되면 Settings → Pages에 표시되는 홈페이지 주소로 접속합니다.

데이터를 갱신할 때는 `index.html` 내부 데이터와 `data.json`을 함께 갱신해야 합니다. 이 대시보드는 저장된 조사 결과이며 자동 갱신·실시간 접수 현황 조회 기능은 포함하지 않습니다.
